# Тихая бухгалтерия

Детективная игра в стиле 1950-х: дело №1 в вымышленном городе Фэрхейвен. Сайт для игроков и пульт ведущего. Связь и общая история команд идут через бесплатный Firebase Firestore (проект `detective-fh1956-az`, правила в `firestore.rules`).

## Для игроков
Страница `/`. Одна общая ссылка для всех. Игрок вводит код своей команды (ведущий создаёт коды на пульте и выдаёт на бумажке). Первый вошедший называет команду, остальные заходят по тому же коду и видят общую историю. Дальше расследование:
- запросы по адресам города (например `П-12`), по картотекам (`В-44/Имя Фамилия`) и телефонным номерам;
- найденные приложения открываются на экране, улики можно предъявлять людям, для обыска нужен ордер;
- справочник с картой города;
- в конце команда вписывает свои ответы.

Прогресс команды общий для всех её устройств (хранится в Firebase, копия в браузере). Код `test` открывает сайт без команды для проверки. Звук включается кнопкой в шапке (по умолчанию выключен).

## Для ведущего
Страница `/host/`:
- кнопки «Начать игру», «Приостановить» (перерыв, сайт у игроков закрывается), «Пауза таймера» (только останавливает часы и подсказки, сайт остаётся открытым), «Продолжить», «Закончить»;
- после конца игры: «Начать заново» (сразу запускает) или «Сбросить игру» (возвращает к «не начата», команды остаются);
- до старта у игроков экран «Дело ещё не поступило», в перерыв доступ закрыт, в конце «Спасибо за игру»;
- таймер, заставки и подсказки для экрана зала: тексты и картинки редактируются на месте;
- «Команды»: задать число, «Создать команды», у каждой свой 6-значный код; таблица с названием, числом участников, запросов и верных ответов;
- «Ответы игроков»: ведущий и раннер (тот же пульт на другом устройстве) отмечают каждый ответ «Верно/Неверно», отметки лежат в Firebase; из них считаются баллы, места и гонорар (баллы × ставка − поездки × ставка поездки, ставки в настройках; при равных баллах выше у кого меньше поездок);
- кнопка «Показать результаты на экране» выводит на экран зала таблицу итогов;
- «Новая игра» обнуляет список команд;
- QR/ссылка на общий вход для экрана зала.

Подсказки и настройки хранятся в браузере ведущего, в репозиторий они не попадают.

Ограничение: правила Firestore открыты для тех, кто знает код игры/команды. Автоматической проверки ответов нет, оценка ручная. Для вечеринки достаточно, для коммерческого запуска стоит добавить авторизацию.
