# Тихая бухгалтерия

Детективная игра в стиле 1950-х: дело №1 в вымышленном городе Фэрхейвен. Сайт для игроков и пульт ведущего, оба работают без сервера. Связь между ними идёт через бесплатный публичный канал ntfy.sh.

## Для игроков
Страница `/`. Команда открывает ссылку от ведущего (`/?g=КОД`) или вводит код игры, называет команду и расследует дело:
- запросы по адресам города (например `П-12`), по картотекам (`В-44/Имя Фамилия`) и телефонным номерам;
- найденные приложения открываются на экране, улики можно предъявлять людям, для обыска нужен ордер;
- справочник с картой города;
- в конце команда вписывает свои ответы.

Прогресс хранится в браузере устройства. Звук включается кнопкой в шапке (по умолчанию выключен).

## Для ведущего
Страница `/host/`:
- кнопки «Начать игру», «Приостановить» (перерыв), «Продолжить», «Закончить»;
- до старта у игроков экран «Дело ещё не поступило», в перерыв доступ закрыт, в конце «Спасибо за игру»;
- таймер, заставки и подсказки для экрана зала: тексты и картинки редактируются на месте;
- код игры и QR для игроков.

Подсказки и настройки хранятся в браузере ведущего, в репозиторий они не попадают.

## Файлы
- `index.html` — сайт игроков, один файл.
- `host/index.html` — панель ведущего, один файл.
