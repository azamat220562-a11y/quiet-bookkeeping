# Тихая бухгалтерия

Детективная игра в стиле 1950-х: дело №1 в вымышленном городе Фэрхейвен. Сайт для игроков, одна страница без сервера.

## Как играть
1. Команда открывает страницу на телефоне или ноутбуке и вводит название.
2. Запросы делаются по адресам города (например `П-12`), по картотекам (`В-44/Имя Фамилия`) и телефонным номерам.
3. Найденные приложения открываются на экране. Улики можно предъявлять людям, а для обыска нужен ордер.
4. В конце команда вписывает свои ответы на шесть вопросов.

Прогресс команды хранится в браузере устройства. Сброс: «Служебное» внизу страницы.
